## Actual input and execution

The input consists of stored rational matrix rows, natural endpoint pairs in the seed/selected/host lists, and a literal list of drawn-edge lists. The edge scanner reads one stored pair at a time, compares both orientations, and stops at the first match. Duplicates and orientation do not alter finite-set semantics, but every cell actually read is charged. Four scans compute all membership fields of each record. Row and matrix reversals are explicit cell transitions.

For a represented n-by-n matrix and four lists with total length L, constructing its exact inherited SampleRecords.encode value takes at most n^2*(L+11)+4*n+2 successful transitions. There is no supplied membership bit or membership callback.

The caller traverses all literal draws, runs this constructor for each, reverses the completed record list, and passes that very list to the inherited sample-vote controller. That controller performs actual matrix clipping, distance scans and success/failure accumulation. The final result is the same empirical 3/8 test, including the zero-draw convention. The proved bound is m*(n^2*(|Q|+|E|+|T|+11)+4*n+perSample(n)+5)+n^2*D+4, where D counts all stored cells across the drawn-edge lists, including duplicates. Every constructor, reversal, submachine call and final handover is included.
