# Unverified finite-prefix realization component

This new module supplies a fixed finite-list bit reader and proves that every depth-bounded binary draw tree consumes an actual suffix of the same input. A uniform independent prefix of the maximum required length gives exactly the tree's fair-bit output law. The existing whole-monad decoder refinement transfers both statements to the actual direct monadic bounded decoder, without restarting the source between adaptive draws. Bounded-rejection bias remains explicit.

The core binary-tree suffix/output-law proofs compiled strictly in a local prototype using exact extracted definitions. Full production build, strict compilation, exhaustive axiom audit, kernel replay and independent semantic review remain required. All193 verified baseline proof files are unchanged.

The direct monadic decoder uses Fin2 bit values. This component does not claim the final encoded binary callback and its physical ledger have already been connected to the same finite source. Physical arithmetic, memory and whole-program runtime joins remain separate. It does not complete the paper or change its Site status.
