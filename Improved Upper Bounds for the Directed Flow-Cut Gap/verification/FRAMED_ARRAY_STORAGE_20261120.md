# Typed input arrays and vertex source storage

The original typed vertex and edge parsers assemble rows and outer vectors with the certified array constructors. They preserve the validated values, ordered demands and earlier charge formulas. Each schedule follows the row decoder up to rejection. A failed row retains the schedule for earlier rows. Extra trailing input skips typed assembly.

`PhysicalSourceInputJoin.vertex_arrays` and `edge_arrays` bound the modeled copies, reserved cells and address widths for typed assembly on every literal source. `FramedVertexStorage.array_polynomial` joins the typed input schedule to the completed vertex fractional cache walk and the schedule for its returned rows or mask. It uses the same parsed input and terminal plan. The natural and binary reservation traces agree from any starting address.

The traces model persistent array copies. The full source-to-cut bit-time bound still requires width-sensitive accounting for the framer’s heap and lists, the outer graph transformations, and rounding and selection. The typed source fixture retains padded prices and ordered rows in both modes. A malformed second row leaves the first row’s 54 modeled instructions and 19 cells. A trailing bit yields zero typed reservations.
