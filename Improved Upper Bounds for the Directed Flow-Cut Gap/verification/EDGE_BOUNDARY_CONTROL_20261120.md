# Indexed edge input and output projections

`BinaryEdgeProjection.matrixWithControl` fills the rows through a single callback for each typed index. The raw input-price decoder accounts for the reached read of each stored fraction. The fractional row projection reads the arc slots. Cut projection masks off non-arcs before reading the line mask. The infeasibility projection checks both witness ports. Lifting an original edge mask assigns `false` to ports and reads the original mask only for arc labels. Each projection preserves its earlier result and fee.

`PaidDirectEdgeWire.edgeWithBoundaryControl` returns the same paid result, including any unread tape, and records the additional work for original price decoding, line preparation and final output. `wire_boundary_polynomial` bounds the sum of those three fields by a polynomial in the source length for both modes and every tape. `wire_work_with_boundary_polynomial` includes the earlier mixed recorded charge. The separate fractional row and mask lift bounds apply to individual calls. Their work across all attempted rounds, gadget construction and width-sensitive costs of the other source-to-cut phases remain open.

The original 44-bit fixture returns the single demanded edge and preserves the unread tape and earlier fee of 1,784,110,573. It records 11,660 price, 168,857 line and 12,979 output operations. A trailing source bit gives the earlier fee of 430,370 and zero boundary work. The witness case checks the correct port pair and rejection of an arc in a port slot. It also checks the projected fractional rows and lifted edge mask.
