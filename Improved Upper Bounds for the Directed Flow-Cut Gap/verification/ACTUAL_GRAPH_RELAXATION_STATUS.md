# Actual adjacency-driven graph relaxation

The fixed 532-slot program performs one tail-first relaxation scan over represented previous walk records. It reads the actual Boolean adjacency matrix with real binary-indexed pointer traversals. On a true adjacency branch it allocates the literal directed edge, reads the original source-zero row cost, calls canonical rational addition, and constructs the real new walk record. The exact costed head then competes with the actual tail answer using the real rational comparator; equal costs retain the head. Absent edges are skipped by the loaded flag, not by a denotational callback.

All calls retain actual saved registers and caller frames, append to the same immutable heap, and preserve the source reader. The proof exposes exact successful-instruction and allocation recurrences. Its input-derived bound is linear in the represented entry count and polynomial in field/label widths and numeric label cap. The complete lower interpreter runs once, retains the original table/context, returns the computed walk or nil, and pays one final halt. The graph adapter derives matrix/index and source-zero equalities and returns the exact old BinaryFractionalWalkOracle.scan candidate, including its padded original edges, canonical fields and stable tie rule.

StoredWalk is a representation predicate. Graph validity of a supplied previous walk is not built into that predicate; the scan refines the original recurrence on arbitrary represented previous records. The actual adjacency check certifies the new edge. A later bounded-round invariant must establish the full produced walk's endpoint, graph support and optimality properties. No precomputed result, favorable cost or abstract adjacency/arithmetic callback is assumed.
